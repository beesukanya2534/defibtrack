# DefibTrack

เว็บแอปสำหรับบันทึกและสรุปผลการตรวจเช็คเครื่องกระตุกหัวใจไฟฟ้า (Defibrillator) รายเดือน แยกตามหน่วยงาน
พร้อมจัดอันดับ สร้างรายงานสรุปภาษาไทยอัตโนมัติ และส่งออกเป็น `.txt` / `.csv` / PDF

มี 2 มุมมอง สลับด้วยเมนูด้านบน:

- **บันทึกข้อมูล** — กรอก/แก้ไขข้อมูลของเดือนที่เลือก พร้อมรายงานสรุปสด
- **ดูข้อมูลย้อนหลัง** — ตารางสรุปรวมทุกเดือน และเลือกเดือนย้อนหลังเพื่อดูรายงานเต็ม + ตารางอันดับ

## ข้อมูลเก็บที่ไหน

ข้อมูลเก็บเป็นไฟล์ใน **โฟลเดอร์บนคอมพิวเตอร์** ที่เลือกไว้ (ไม่มีเซิร์ฟเวอร์ ไม่มีฐานข้อมูลออนไลน์):

```
<โฟลเดอร์ที่เลือก>/
  defibtrack-data.json                 ข้อมูลทั้งหมด (ทุกเดือน + รายชื่อหน่วยงาน)
  backups/defibtrack-YYYY-MM-DD.json   สำเนาของการบันทึกครั้งสุดท้ายในแต่ละวัน
```

- ต้องใช้ **Google Chrome หรือ Microsoft Edge** (ใช้ File System Access API เขียนไฟล์ลงเครื่อง)
- ครั้งแรก: คลิกป้ายสถานะมุมขวาบน → เลือกโฟลเดอร์ (เช่น `C:\Users\<ชื่อผู้ใช้>\DefibTrack`)
- ครั้งต่อไป เบราว์เซอร์อาจถามสิทธิ์อีกครั้ง → คลิกป้ายสถานะ หรือกดบันทึก แล้วกด "อนุญาต"
  (เลือก "อนุญาตทุกครั้งที่เข้า" ได้ถ้าเบราว์เซอร์มีตัวเลือกนี้)
- เบราว์เซอร์เก็บสำเนาไว้ใน IndexedDB ด้วย เพื่อแสดงข้อมูลได้ก่อนให้สิทธิ์โฟลเดอร์ แต่ **การบันทึกจะเขียนลงไฟล์เสมอ**
- ถ้าไฟล์ในโฟลเดอร์กับสำเนาในเบราว์เซอร์ต่างกัน แอปรวมให้อัตโนมัติ (เดือนเดียวกันใช้อันที่บันทึกล่าสุด)
- ข้อมูลอยู่เครื่องเดียว — ถ้าจะสำรองหรือย้ายเครื่อง ให้คัดลอกทั้งโฟลเดอร์
- ถ้า `defibtrack-data.json` เสียหาย แอปจะไม่ยอมบันทึกทับ ให้คัดลอกไฟล์ล่าสุดจาก `backups/` มาแทน

ไฟล์ข้อมูลถูกกันไว้ใน `.gitignore` — ห้ามนำไฟล์ข้อมูลขึ้น repo นี้ (เป็น repo สาธารณะ)

## เกณฑ์พิเศษ: หน่วยงานไตเทียม

หน่วยงานที่ชื่อมีคำว่า "ไตเทียม" ตรวจเช็คเฉพาะเวรเช้าในวันทำการ (N = วันทำการของเดือน):
ครบ = N เวร · ตรวจเช็คบ่อยครั้ง = 15 ถึง N-1 เวร · น้อยกว่าเกณฑ์ = 1–14 เวร · ไม่ได้ตรวจ = 0 เวร

N ค่าเริ่มต้นคือจำนวนวันจันทร์–ศุกร์ แก้ได้ที่ช่อง "วันทำการ (ไตเทียม)" (`WORKDAY_HIGH_MIN` ใน `index.html`)
